# 회계·세무 포털 사용법

공시·신고·납부 일정을 달력으로 보고, 용어집·기초교육·Q&A를 한곳에서 찾아보는 단일 HTML 포털입니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 포털 본체(C 시안, 라일락). 파일 하나로 동작합니다. |
| `files/calendar-guide-cal-001.pdf` | 달력 기능 가이드라인 |
| `files/glossary-sample-fa-003.pdf` | 회계·세무 실무 용어집 |
| `files/basic-guide-sample-fa-004.pdf` | 업무처리 기초 가이드 |
| `이전버전/` | 이름을 바꾸기 전 원본 사본 (`portal-lilac-original.html`) |

## 열기

`index.html`을 더블클릭해 브라우저(Chrome, Edge 등)로 엽니다. 서버나 설치는 필요 없고, 인터넷 연결 없이도 동작합니다.

## 메뉴

상단 메뉴: 홈 · 회계세무 달력 · 용어집 · 기초교육 · Q&A · 자료실

모바일(화면 폭 640px 이하)에서는 메뉴가 햄버거(≡) 버튼으로 접힙니다. 버튼에는 지금 보고 있는 영역 이름이 표시되고, 눌러 펼친 메뉴에서 항목을 누르면 자동으로 닫힙니다(바깥 영역 터치, Esc 키로도 닫힘). 스크롤 위치에 따라 현재 영역의 메뉴가 강조됩니다.

### 회계세무 달력
- **연도 이동**: ◀ ▶ 버튼 또는 연도 선택, `오늘` 버튼으로 현재 달로 돌아옵니다.
- **구분 표시**: ● 공시, ▲ 세금 신고, ■ 세금 납부. 색과 글자(라벨)를 함께 씁니다.
- **필터**: 구분 필터와 대상 필터로 보고 싶은 일정만 걸러 봅니다.
- **날짜 선택**: 날짜를 누르면 오른쪽에 그날 일정 상세가 열립니다. 다가오는 일정은 별도 목록으로 보여 줍니다.
- **휴일 이월**: 신고·납부 기한이 토·일·공휴일이면 다음 영업일로 옮겨 표시합니다(대상 일정에 한함).
- **연도 배너**: 공휴일이 등록되지 않은 연도는 이월 전 원래 기한을 보여 주고 안내 배너를 띄웁니다.

### 용어집
검색창에 용어를 입력하거나 분류 칩(전체, 회계 기본, 결산, 재무비율, 세무, 그룹회계, 공시)을 눌러 걸러 봅니다. 검색 결과 수가 함께 표시됩니다.

### 기초교육
탭 5개(세금계산서, 부가세 신고 일정, 원천징수, 월말 결산, 법인세·기업업무추진비)를 눌러 전환합니다. 방향키로도 탭을 옮길 수 있습니다.

### Q&A
질문 10개를 눌러 펼치고 접습니다.
검색창에 단어를 입력하거나 카테고리 버튼(전체, 공시, 달력, 법인세, 부가세, 세금계산서, 원천징수, 증빙)을 누르면 해당 질문만 보입니다. 질문과 답변 본문을 함께 검색하며, 개수가 함께 표시됩니다.

### 자료실
`files/` 폴더의 PDF 3개를 목록(파일명·설명·용량)으로 보여 주고, 다운로드 버튼을 누르면 새 창 없이 바로 내려받습니다. 저장되는 파일명은 한글 원래 이름입니다. 파일을 추가하려면 `index.html`의 `id="library"` 구간에 `<li>` 항목을 복사해 `href`와 `download` 값을 바꿉니다.

### 다크 모드와 맨 위로 버튼
- 상단 메뉴 오른쪽의 `다크`/`라이트` 버튼으로 화면 색을 바꿉니다. 처음 열 때는 기기의 다크 모드 설정을 따르고, 한 번 바꾸면 그 선택을 브라우저에 기억합니다. 인쇄는 항상 밝은 색으로 나옵니다.
- 아래로 조금 내려가면 오른쪽 아래에 `↑` 버튼이 나타나고, 누르면 맨 위로 올라갑니다.

## 일정 데이터 수정

`index.html` 안의 `PURE:START` ~ `PURE:END` 구간에 공휴일(`HOLIDAYS`)과 일정 규칙(`EVENTS`)이 있습니다.

- 일정 규칙 종류: `fixed`(매년 같은 월일), `monthly`(매월), `days_after`(기준일 + n일), `manual`(연도별 직접 입력)
- 휴일 이월은 `shift:true`인 일정에만 적용되며, 공휴일이 등록된 연도에서만 작동합니다.
- 공휴일은 현재 2026~2027년만 등록되어 있습니다. 다른 연도를 쓰려면 `HOLIDAYS`에 추가합니다.

## 공개 전 확인할 것

- 모든 일정에는 "검증 전" 상태가 표시됩니다. 법령·고시와 대조한 뒤 상태를 바꿉니다.
- 공휴일(2026~2027), 감사보고서 제출 기한, 세율·가산세율·기준금액은 공식 자료로 확인해야 합니다. 이 포털은 일반 안내용이며 개별 사안의 세무·법률 판단을 대신하지 않습니다.
- 외부에 공개하는 포털이므로 회사 내부 정보나 개인정보는 넣지 않습니다.
